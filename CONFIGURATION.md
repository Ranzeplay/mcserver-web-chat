# Configuration System

This document describes the configuration system implemented for MCServer Web Chat, which includes both backend configuration and web build-time configuration.

## Backend Configuration

The backend configuration is managed by `ConfigService.java` and stored in `config/mcserver-web-chat/config.json`.

### Available Settings

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| `language` | string | `"en-us"` | Server language |
| `webPort` | integer | `8080` | Web server port |
| `enableDebugLogging` | boolean | `false` | Enable debug logging |
| `baseUrl` | string | `"http://localhost:8080"` | Base URL for the web server |
| `websocketPath` | string | `"/ws"` | WebSocket endpoint path |
| `serverName` | string | `"MCServer Web Chat"` | Display name for the server |
| `enableCors` | boolean | `true` | Enable CORS support |
| `staticResourcePath` | string | `"/static"` | Path for static resources |

### Usage

```java
ConfigService config = ConfigService.getInstance();

// Get values
int port = config.getWebPort();
String baseUrl = config.getBaseUrl();
String wsPath = config.getWebsocketPath();

// Set values
config.setWebPort(9090);
config.setBaseUrl("http://example.com:9090");
config.setWebsocketPath("/websocket");
```

### Configuration File Location

The configuration file is automatically created at:
```
<minecraft-server-dir>/config/mcserver-web-chat/config.json
```

Example configuration file:
```json
{
  "language": "en-us",
  "webPort": 8080,
  "enableDebugLogging": false,
  "baseUrl": "http://localhost:8080",
  "websocketPath": "/ws",
  "serverName": "MCServer Web Chat",
  "enableCors": true,
  "staticResourcePath": "/static"
}
```

## Web Build-Time Configuration

The web frontend includes a build-time configuration system that generates configuration metadata during the build process.

### Build Configuration Generation

The build configuration is automatically generated by `scripts/generate-build-config.js` during the build process:

```bash
npm run build  # Automatically runs prebuild script to generate config
```

### Generated Configuration

The generated `src/config/build-config.ts` contains:

```typescript
export interface BuildConfig {
    buildTime: string;        // ISO timestamp of build
    version: string;          // Package version
    buildEnvironment: string; // NODE_ENV value
    backend: {
        defaultPort: number;
        defaultBaseUrl: string;
        defaultWebsocketPath: string;
        defaultStaticPath: string;
    };
    build: {
        timestamp: number;    // Unix timestamp
        nodeVersion: string;  // Node.js version used
        platform: string;     // Build platform
    };
}
```

### Runtime Configuration Service

The web frontend includes a `configService.ts` that provides runtime configuration management:

```typescript
import configService from './services/configService';

// Get current configuration
const config = configService.getConfig();

// Update backend settings
configService.updateBackendConfig({
    port: 9090,
    baseUrl: 'http://example.com:9090'
});

// Update UI settings
configService.updateUIConfig({
    theme: 'dark',
    language: 'zh-cn'
});

// Get connection URLs
const backendUrl = configService.getBackendUrl();
const wsUrl = configService.getWebSocketUrl();

// Get build information
const buildInfo = configService.getBuildInfo();
```

### Configuration Persistence

Runtime configuration changes are automatically persisted to localStorage and will be restored on page reload.

### Components

- **BuildInfo**: Displays build-time information
- **ConfigDemo**: Interactive configuration demonstration

## Integration

The backend `WebServer.java` now uses the configuration service:

```java
public class WebServer {
    private final ConfigService configService;
    
    public void start() {
        int port = configService.getWebPort();
        String wsPath = configService.getWebsocketPath();
        // ... use configuration values
    }
}
```

## Development

To add new configuration options:

### Backend
1. Add property to `createDefaultConfig()` in `ConfigService.java`
2. Add getter/setter methods
3. Update consuming code to use the new setting

### Web
1. Update `generate-build-config.js` if needed for build-time values
2. Update `RuntimeConfig` interface in `configService.ts` for runtime values
3. Add UI controls in `ConfigDemo.tsx` for user configuration
